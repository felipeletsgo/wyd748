## How to regenerate

```powershell
python .agents/research/data-consistency.py --tsv .agents/research/client748/inventory/item-data-differences.tsv --markdown DOCS/protocol/data-consistency.md
```

`ItemList.bin` records are 140 bytes, XOR `0x5A`, with a 4-byte trailer. The
file layout differs from the in-memory `STRUCT_ITEMLIST`: after the 12 static
effects, `price` is an int at `@128`, then `unique`, `pos`, `extra` and `grade`
are shorts at `@132-@138` (proven on items 1, 1101 and 2000). Each side names
effects with its own `ItemEffect.h` (the server says `EF_ITEMLEVEL` where the
client says `EF_REFLEVEL`); the comparison uses the numbers.

## Findings and recommended decisions (2026-10-03)

Decision rule (project owner, 2026-10-03): the TMProject was built for a newer
client and accepts more modern structures. Native 7.48 evidence informs the
decision but is not the default; when the TMProject or the server has a
superior structure, keep it, documented and tested. Port the native form only
where no working superior equivalent exists.
