## How to regenerate

```powershell
python .agents/research/ui-matrix.py --tsv .agents/research/client748/inventory/ui-matrix.tsv --markdown DOCS/client/ui-compatibility-matrix.md
```

Resource controls are read from the runtime RC files with the record sizes the
client compiles (`internal/ui/UIBinary.h`). Native bindings are calls to the
control container's `FindControl` (virtual slot `0x48` of the container at
scene `+0x28`), directly or through a local copy of the container pointer.
TMProject bindings are the constant arguments of `FindControl`; an ID built at
run time (`base + i`) appears only through its constant base, so some N rows can
be bound by a loop in the TMProject.

### Removal batch 1 (2026-10-03): the 7.48 field scene is the only mode

The field scene decided at start-up between the native `FieldScene2` path and
the later client's HUD by looking up control 66817, which no 7.48 resource
contains; the flag `m_bCompatFieldScene` then selected one of two code paths
in about 100 places. The 7.48 runtime only ever took the native path, so the
other one was dead code that bound 7.69 controls. Batch 1 removed it:

- `InitializeScene` calls the 7.48 initializer only; the 7.69 HUD binding
  (`BindChatAndHudControls` and its helpers) is gone.
- The tails of `FrameMove`, `OnMouseEvent` and 15 other methods after their
  7.48 early return were deleted; `flag ? 7.48 : 7.69` expressions keep the
  7.48 value; `m_bCompatFieldScene` no longer exists.
- 18 methods reachable only from the removed code were deleted (`MobMove`,
  `OnPacketCreateMob`, `UpdateWeatherEffects`, the Khepra effects and others).
  Methods that were already unused before this batch stay for a later pass.
- Policies that take the mode as a parameter (`field_chat::Handle`,
  `QuickSlotIndex`, `AutoTradeSlotIndex`, `WYD748_IsUnsupportedCompatEquipSlot`,
  `MaximumTextFormat`) now receive `true`; simplifying them is the next batch.

Result: X fell from 417 to 73 IDs and the TMProject binds 306 IDs instead of
639. Validation: Release build, architecture tests (1,145,527 checks) and
socket tests (221) pass; the source contract tests now describe the single
lifecycle; the relocation gates accept the change only through the recorded
reviews in `.agents/research/relocations/tmfieldscene-reviews.json` and
`tmhuman-reviews.json` (`--review` writes them; any later edit to a reviewed
body fails the gate). Pending: `CLIENT-TESTED`.
