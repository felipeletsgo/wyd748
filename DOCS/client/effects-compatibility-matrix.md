## How to regenerate

```powershell
python .agents/research/effects-matrix.py --tsv .agents/research/client748/inventory/effects-matrix.tsv --markdown DOCS/client/effects-compatibility-matrix.md
```

Native branches come from the decompiled corpus (`FUN_00489a3e` for the attack
packet, `FUN_00506f9d` for the deferred effect event; see the
`skill-visual-dispatch` research record). TMProject classes are sized by the
compiler; a class that grew in the newer client is mapped to its native size
from the branches where both sides allocate one object (for example
`TMEffectBillBoard`, 388 bytes, native `0x180`). Allocations are counted where
they appear in the source, not how often a loop runs them.
