## How to regenerate

```powershell
python .agents/research/resource-matrix.py --tsv .agents/research/client748/inventory/resource-matrix.tsv --markdown DOCS/client/resource-compatibility-matrix.md
```

Native paths are exported from the Ghidra project
`tmproject/build/native-research/WYD748.gpr` by `ExportWydPathStrings.java`
(headless, `-readOnly -noanalysis`). A row is a lead: whether and how a loader
reads a file (record size, count, checksum) is the R2 format contract.
Resource scripts named `.txt` are loaded as compiled `.bin` by the native RC
loader (`FUN_0049e1e3`, format `"%s.bin"`); such rows show `as .bin`.

## Findings and recommended decisions (2026-10-03)

Decision rule (project owner, 2026-10-03): the TMProject was built for a newer
client and accepts more modern structures. Native 7.48 evidence informs the
decision but is not the default; when the TMProject or the server has a
superior structure, keep it, documented and tested. Port the native form only
where no working superior equivalent exists.
