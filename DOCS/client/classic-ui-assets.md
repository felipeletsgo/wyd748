# Classic UI assets

The client always runs the modern UI (`g_UIVer = 2`, as native
`FUN_0055bc0a` does; see the [UI compatibility matrix](ui-compatibility-matrix.md)).
The assets below serve only the classic UI. Removing them makes the runtime
about 4.7 MB lighter, roughly 0.5% of `tmproject/client748` (973 MB): a small
gain, mainly in package size, since the client loads a texture only when a
control or effect asks for it.

Generated by `.agents/research/ui-asset-usage.py` (read-only). A texture file is
classic-only when every texture set that reaches it (`UI/UITextureSetList.txt`
-> `UI/UITextureList.bin`) appears only in the classic scene resources
(`FieldScene.bin`, `SelCharScene.bin`, `SelServerScene.bin`, `LoginScene.bin`),
and no client source line handling texture sets, no direct path or path
pattern (client or native), and no other runtime list (Effect, Mesh, Env)
names it. The client loads only the modern scene resources (`*2.bin`).

Decision rule: remove only after approval and a client run of the four
modern scenes; keep the files of the last section until their use is traced
(`pck_backimage02..04` follow `pck_backimage01`, which a set uses, and may be
selected by index at run time). `LoginScene2.bin` is also never loaded by the
client but is not classic; it is out of this list.
