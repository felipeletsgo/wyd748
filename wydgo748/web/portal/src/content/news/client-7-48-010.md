Client 7.48.010 accompanies the server corrections for city binding and return teleports. Confirmed movement selects the last city reached. The return scroll and restart use the bound city's native return area; an owned guild territory takes priority. The correction also resolves the persistence ordering that could disconnect a player when walking into a city.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before starting. The accompanying server requires client 7.48.010. Automated client, server and database checks passed. Actual gameplay acceptance remains pending.
