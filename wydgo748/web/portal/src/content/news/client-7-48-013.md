Client 7.48.013 corrects the item-grid icons for the Master capes of Hekalotia, Akeronia and Adventurer. Each cape now reuses the matching Elite cape icon. This changes the inventory and equipment icon only; the item and its appearance in the world remain unchanged.

The client no longer starts a second process that attaches to the game for crash monitoring. Crash capture remains in the game process.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before starting. The accompanying server requires client 7.48.013. Automated checks passed; actual gameplay acceptance remains pending.

Português: o client 7.48.013 corrige os ícones das capas Mestre de Hekalotia, Akeronia e Aventureiro. Cada capa reutiliza o ícone correspondente da capa Elite. A mudança afeta somente o ícone no inventário e nos equipamentos; o item e sua aparência no mundo permanecem iguais.

O client não inicia mais um segundo processo anexado ao jogo para monitorar falhas. A captura continua dentro do processo do jogo.

Atualização obrigatória: feche o jogo, abra WYDLauncher.exe e aguarde a atualização antes de iniciar. O servidor correspondente exige o client 7.48.013. Os testes automatizados passaram; a validação dentro do jogo continua pendente.
