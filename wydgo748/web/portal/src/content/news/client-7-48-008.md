Premium Nell now uses the official store artwork and layout inside the game window, fills the game area and provides a close button in the upper-right corner. Browse six items per page, search the catalog and select Featured, Armia, Erion or Nifleheim. Staff can assign each item to its category in the existing catalog panel. Existing items remain in Featured until edited.

The shop and category controls support English and Brazilian Portuguese. Purchases continue to use the server catalog, balance validation and duplicate-request protection. Microsoft Edge WebView2 Runtime is required for the embedded interface.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before pressing Start. The accompanying server requires client 7.48.008. Install full client 7.48.001 first if needed, then apply the patches in order. Automated checks passed; purchases and the updated embedded interface still require in-game confirmation.

Português: o Premium Nell agora usa a arte e o layout da loja oficial, ocupa a área do jogo e possui botão de fechar no canto superior direito. A loja exibe seis itens por página, busca e categorias Destaque, Armia, Erion e Nifleheim. As categorias podem ser configuradas no painel existente; os itens atuais permanecem em Destaque até serem editados.

Atualização obrigatória: feche o jogo, abra WYDLauncher.exe e aguarde a atualização antes de iniciar. O servidor exige o client 7.48.008. É necessário ter o Microsoft Edge WebView2 Runtime instalado. As verificações automatizadas passaram; a interface integrada e as compras ainda precisam de confirmação dentro do jogo.
