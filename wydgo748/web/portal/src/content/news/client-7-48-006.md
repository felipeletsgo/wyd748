Premium Nell opens an embedded WebView2 window with English and Brazilian Portuguese text, catalog search, item details and purchase confirmation. Catalog items continue to be managed through the existing staff panel. Purchases use authoritative server validation and duplicate-request protection.

The browser is created when Premium Nell opens and released when its window closes. Microsoft Edge WebView2 Runtime is required for the embedded interface; the native shop is used when that runtime is unavailable.

The accompanying server release removes retained monsters when an instance ends, includes channel corrections and preserves the reviewed NPC population. The Gargoyle Molar quest uses displayed Mortal levels 201 through 205.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before pressing Start. The updated server requires client 7.48.006. Install full client 7.48.001 first if needed, then apply the patches in order. Existing account data, settings and language preferences are preserved.

Automated validation and publication are tracked separately from gameplay acceptance. Test Premium Nell opening and closing, real purchases in both languages and leaving and reentering an instance after updating.
