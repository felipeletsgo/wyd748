Client 7.48.003 corrects a text rendering regression introduced in 7.48.002. Interface letters retain their original size. Character and skill captions that exceed their available space use an ellipsis, while ordinary labels, names and numeric values keep their existing layout.

Every client update is mandatory. Close the game, open WYDLauncher.exe and wait for updates before pressing Start. The server requires the build compiled into client 7.48.003 before login. Editing config.txt cannot bypass this check. Existing language preferences are preserved.

Install full client 7.48.001 first if you still use an installation from the retired release line. The launcher then applies the current patches in order.

Automated text layout and build checks passed. In-game confirmation across resolutions and corrected screens remains pending; report any remaining unreadable or overlapping text.
