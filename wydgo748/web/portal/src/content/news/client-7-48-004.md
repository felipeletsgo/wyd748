Channel 2 uses the official 7.59 population generator with templates adapted to the 7.48 client. Channel 1 keeps its separate population. Items unsupported by this client have been removed from the imported templates, and invalid generator groups remain disabled for review. Some specialized NPC services still require further implementation and validation.

The launcher installs the updated executable, server list, server group names and English and Brazilian Portuguese NPC messages. Select WYD-Go and then channel 1 or channel 2. In the world, use srv 1 or srv 2 to request a transfer. Leave combat, instances, trades and personal shops before transferring.

Every client update is mandatory. Close the game, open WYDLauncher.exe and wait for updates before pressing Start. Client 7.48.004 is required by the updated server. Existing account data, settings and language preferences are preserved.

Install full client 7.48.001 first if you still use the retired release line. The launcher applies the current patches in order. Automated checks passed; actual gameplay confirmation for transfers and all NPC services remains pending.
