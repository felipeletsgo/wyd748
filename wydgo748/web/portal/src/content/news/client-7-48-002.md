Client 7.48.002 corrects panel text fitting, accented-text rendering and measurement, quest subject validation, and command help in English and Brazilian Portuguese. The -- chat prefix is global and can be read by every online player on this server.

Every client update is mandatory. Close the game, open WYDLauncher.exe and wait for updates before pressing Start. The server checks the build compiled into the game executable before login. Editing config.txt or copying an old executable over the update cannot bypass this check. Your language preference is preserved.

The current release line began with full client 7.48.001. Install that full client if you still use a client from the retired release line, then update it to 7.48.002 through the launcher. Earlier 100xx patches cannot upgrade an old installation into this release line.

The Colosseum inner gates open with the first wave at minute 6. Monster hits in the event are capped at 1 damage before absorption; player combat is unchanged. Player physical attack uses STR/3 + DEX/8, and DEX no longer adds defense.

Reserved legacy commands return an explicit unavailable notice instead of accidentally sending their arguments as private messages. Citizenship departure, guild rank handover and the legacy war command are not enabled by this update. Characters in a guild must leave it before citizenship departure can be considered.

Automated checks passed. In-game confirmation of every corrected screen and event remains pending; report any text that still overlaps or renders incorrectly.
