The client update corrects Gryphon flight progression and includes the current English and Brazilian Portuguese Help and NPC messages. Both channels remain available through the launcher server list.

The accompanying server update enables the three Perzen exchanges. A Normal sphere grants a Shire Horse, a Mystic sphere grants a Clydesdale Horse, and an Arcane sphere grants a Thoroughbred Horse. Each reward lasts 30 days from its first equip. The exchange consumes one sphere and charges no gold. The Mystic exchange accepts displayed levels 1 through 400.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before pressing Start. The updated server requires client 7.48.005. Existing settings, account data and language preferences are preserved.

Install full client 7.48.001 first if needed, then let the launcher apply the patches in order. Automated validation and in-game acceptance are tracked separately; actual Gryphon travel and all three Perzen exchanges still require gameplay confirmation.
