Client 7.48.011 updates class skills and passives with the reviewed server rules and delivers matching English and Brazilian Portuguese descriptions. It corrects BeastMaster form switching, Thorn Wall collisions and damage, Rapid Hit targeting, continuous attack, the Berserk weapon effect and costume faces.

Holy Judgement preserves at least 1 HP for a living caster. Cancellation blocks potion use on a target without Immunity; otherwise it removes one Immunity effect.

Every client update is mandatory. Close the game, run WYDLauncher.exe and wait for updates before starting. The accompanying server requires client 7.48.011. Automated checks passed; actual gameplay acceptance remains pending.
