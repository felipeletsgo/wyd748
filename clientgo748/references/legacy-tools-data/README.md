# Dados históricos das ferramentas

Snapshot somente leitura dos arquivos de dados encontrados em
`SERVER 7.54/Tools`. Foram preservadas variantes de ItemList, Itemname,
SkillData, itemhelp, nomes de skills e a tabela histórica de efeitos para
comparação e conversão campo a campo.

Executáveis, DLLs e arquivos compactados de editores não foram copiados: não
são necessários para o client Go, não são reproduzíveis e não constituem
evidência nativa 7.48. Estes dados são referência secundária; em divergências,
prevalecem o consumidor atual, os dados autoritativos do servidor, os assets
7.48 e a evidência Ghidra.
